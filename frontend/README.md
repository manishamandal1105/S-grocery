# S-Grocery Frontend

React, TypeScript, Tailwind CSS, এবং Lucide Icons দিয়ে তৈরি ভয়েস-বান্ধব মুদির দোকান ম্যানেজমেন্ট লগইন পেজ।

## 🚀 লোকাল সার্ভার চালু করার নিয়ম:

```bash
# ১. frontend ফোল্ডারে ডিপেনডেন্সি ইন্সটল করুন
npm install

# ২. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে ভিজিট করুন: `http://localhost:3000`
