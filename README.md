# S-Grocery: Store Management App

একটি সহজ ও ভয়েস-বান্ধব মুদির দোকান ম্যানেজমেন্ট সিস্টেম।

## 📁 প্রজেক্ট ফোল্ডার স্ট্রাকচার

- **`frontend/`** : React + TypeScript + Tailwind CSS Frontend (লগইন, ড্যাশবোর্ড, ভয়েস অ্যাসিস্ট্যান্ট)
- **`backend/`** : Python FastAPI Backend (ভবিষ্যতের পরবর্তী ধাপে যুক্ত করা হবে)

---

## 🚀 Frontend চালানোর নিয়ম

```bash
cd frontend
npm install
npm run dev
```

ব্রাউজারে `http://localhost:3000` ওপেন হবে।
